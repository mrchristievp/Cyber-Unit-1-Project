# AP Cybersecurity Unit 1 — Case File 01

Static classroom website for the Unit 1 investigation **The Friday Afternoon Incident**.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public Pages URL after deployment.

## Notes

- No frameworks, packages, or build step are required.
- Student artifact review progress is stored only in the browser with `localStorage`.
- The case is fictional and contains no real credentials or operational systems.
- The site intentionally does not provide solutions. Pair it with a separate investigation worksheet.
